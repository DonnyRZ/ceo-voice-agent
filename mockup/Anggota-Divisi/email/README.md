# Email verifikasi

[Mockup email bertombol](01-verifikasi-email.png) dibuat menggunakan ImageGen, satu email per gambar. Implementasi HTML responsif mempertahankan logo yang tersedia, tombol hyperlink verifikasi, masa berlaku, dan petunjuk kembali ke browser pendaftaran. Teks alternatif email tetap memuat tautan untuk aksesibilitas; ini bukan jalur aplikasi versi lama.
